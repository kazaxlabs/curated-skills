# Connaissances : index

Les documents de référence de l'entreprise : guides, règlements, fiches de produits, gabarits.
Une ligne par document : le chemin, ce que c'est, la date, la source.

Format :
`- connaissances/<fichier> : <ce que c'est> ; <AAAA-MM-JJ> ; <source : lien ou « fourni par le propriétaire »>`

Pour chercher dans les documents : `node outils/recherche.mjs "mots clés"`.
Jamais de document qui contient des données de clients ou des secrets.
