# Programme de subventions pour l'isolation du grenier

Document fictif, écrit pour les tests de recherche. Aucun montant ni aucune condition réelle.

## Admissibilité

Les propriétaires d'une maison peuvent demander une subvention pour l'isolation du grenier lorsque les travaux
sont faits par un entrepreneur reconnu.

## Démarche

1. Évaluation avant les travaux.
2. Travaux d'isolation.
3. Évaluation après les travaux, puis demande de subvention.
