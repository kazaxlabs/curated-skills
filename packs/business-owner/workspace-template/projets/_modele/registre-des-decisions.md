# Registre des décisions du projet

Les décisions réglées pour ce projet, une entrée par décision, la plus récente en bas.
Les décisions qui touchent toute l'entreprise vont dans le `registre-des-decisions.md` à la racine.

On n'efface jamais une entrée. Pour changer d'avis, on ajoute une nouvelle décision qui indique celle qu'elle
remplace. Jamais de secret ni de nom de client.

Format d'une entrée :

```
## D-0001 : <titre court>
- Date : AAAA-MM-JJ
- Décision : <ce qui est décidé>
- Raison : <pourquoi>
- Options écartées : <les autres choix et pourquoi ils ont été écartés>
- Décidé par : <qui>
- À revoir le : AAAA-MM-JJ (ou « sans objet »)
- Remplace : D-00xx (ou « aucune »)
```
